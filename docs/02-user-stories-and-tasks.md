# 02. User Stories & Tasks: Industry Placement (Speak2Inspire)

This document outlines the user stories, acceptance criteria, and specific task breakdowns for the digital content, web management, and social media tasks executed during the Industry Placement at **Speak2Inspire**.

---

## User Story 1: Front Page & Layout Redesign
* **User Story ID:** US-01
* **As a:** Visitor / Prospective Client (Young person or parent)
* **I want to:** Land on a modern, visually engaging, and clear front page
* **So that:** I can instantly understand Speak2Inspire’s mission, confidence coaching offers, and how to get involved.
* **Acceptance Criteria:**
  1. The front page layout loads correctly and looks professional across both desktop and mobile viewports.
  2. Hero sections, call-to-action (CTA) buttons, and branding elements are up to date.
  3. Edits are implemented live using WordPress and Elementor without breaking layout responsiveness.

### Task Breakdown:
* [x] **T-01.1:** Review employer design briefs and target layouts for the front page.
* [x] **T-01.2:** Update hero text, imagery, and structural components using Elementor.
* [x] **T-01.3:** Conduct cross-browser and mobile responsiveness testing.
* [x] **T-01.4:** Publish updates to the live production site and secure employer sign-off.

---

## User Story 2: Footer & Information Architecture Optimization
* **User Story ID:** US-02
* **As a:** Site Visitor
* **I want to:** Access quick links, contact details, and social media handles easily at the bottom of any page
* **So that:** I can navigate the site smoothly or reach out for inquiries without scrolling back up.
* **Acceptance Criteria:**
  1. The footer is consistent across all main pages.
  2. All navigation links and social icons are functional and lead to the correct external platforms.

### Task Breakdown:
* [x] **T-02.1:** Audit existing footer layout and identify missing or outdated links.
* [x] **T-02.2:** Update copyright text, contact info, and menu items in WordPress/Elementor.
* [x] **T-02.3:** Verify link redirects and test visual alignment.

---

## User Story 3: Service Offers & FAQ Management
* **User Story ID:** US-03
* **As a:** Prospective Coaching Client
* **I want to:** Read clear descriptions of program offers and find answers to common questions quickly
* **So that:** I feel informed and confident before booking or registering for a program.
* **Acceptance Criteria:**
  1. Offers page clearly details pricing, structure, or program benefits.
  2. FAQ section addresses key friction points in a clean accordion or readable format.

### Task Breakdown:
* [x] **T-03.1:** Draft and format updated copy for Speak2Inspire's core coaching offers.
* [x] **T-03.2:** Build and update the FAQ section with clear questions and concise answers.
* [x] **T-03.3:** Review content clarity and check for spelling or formatting errors before publishing.

---

## User Story 4: Multimedia & Video Content Production
* **User Story ID:** US-04
* **As a:** Social Media Audience Member / Prospective Participant
* **I want to:** Watch engaging video content and promotional clips
* **So that:** I can visualize the impact of Speak2Inspire's programs dynamically.
* **Acceptance Criteria:**
  1. Promotional video content is visually compelling, well-paced, and aligned with brand guidelines.
  2. Exported video format is optimized for web/social media posting.

### Task Breakdown:
* [x] **T-04.1:** Conceptualize storyboard/layout for the promotional video requested by the employer.
* [x] **T-04.2:** Design and animate assets, text overlays, and transitions using **Canva**.
* [x] **T-04.3:** Export final video file and deliver it to the employer/publishing queue.

---

## User Story 5: Daily Social Media Operations
* **User Story ID:** US-05
* **As a:** Community Member / Follower
* **I want to:** See consistent, inspiring, and informative posts on Speak2Inspire's social channels daily
* **So that:** I stay engaged with upcoming events, tips, and confidence-building content.
* **Acceptance Criteria:**
  1. Social media platforms are updated daily with relevant graphics and captions.
  2. Tone of posts remains encouraging, youth-focused, and professional.

### Task Breakdown:
* [x] **T-05.1:** Plan and organize weekly content themes aligned with organizational goals.
* [x] **T-05.2:** Design daily graphic assets and write engaging captions.
* [x] **T-05.3:** Publish or schedule content across platforms and monitor engagement.
